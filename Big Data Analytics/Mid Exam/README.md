# Big Data Analytics of Property/Housing (Study Case PT. Ciputra Development Tbk)

## Problem
- Adanya data silos antar unit bisnis PT Ciputra akibat penggunaan sistem dan basis data yang terpisah sehingga menghambat pengambilan keputusan
- Pencatatan manual menggunakan spreadsheet dan dokumen fisik yang menyebabkan data terduplikasi serta tidak konsisten
- Sistem CPMS dan Dashboard Property Management belum terintegrasi penuh dengan sistem keuangan dan manajemen proyek
- Dokumentasi peminjaman data oleh pihak ketiga tidak tercatat dengan baik sehingga menyulitkan proses audit dan validasi

## What to do
- Memetakan karakteristik dataset pada konsep 5Vs Big Data untuk memahami skala dan kompleksitas data properti
- Menyusun kebutuhan data dan pelaporan berdasarkan lapisan Business Architecture mulai dari Strategic, Tactical, hingga Operational
- Mengimplementasikan operasi CRUD dan kompleks query menggunakan GCP BigQuery untuk mengelola dan menganalisis data properti
- Menerapkan analisis data mulai dari descriptive, predictive, hingga optimization untuk pengambilan keputusan strategis

## Insight
- Sentralisasi data melalui Document Management System secara signifikan menghilangkan redundansi dan meningkatkan akurasi validasi data
- Identifikasi cepat properti bernilai tinggi dan analisis rata-rata harga per wilayah untuk strategi pemasaran

## Recommendation
- Kembangkan model predictive analytics berbasis data historis untuk menentukan lokasi strategis dan konsep green development
- Perluas integrasi sistem manajemen dokumen ke seluruh anak perusahaan guna menciptakan single source of truth yang komprehensif

## Tools
- GCP BigQuery
- Kaggle

## Skills
- QueryL SELECT, WHERE, COUNT, HAVING, dan Subqueries 
- Data Analytics: descriptive, forecasting, predictive, dan optimization analytics 
- Big Data Conceptualization: pemetaan karakteristik data perusahaan dengan 5Vs
