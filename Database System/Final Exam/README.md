## Problem
Kesulitan dalam mengelola data donatur yang tersebar dan memastikan pencatatan penyaluran dana tetap akurat

## What To Do
- Merancang database relasional dengan normalisasi hingga 3NF untuk mengurangi duplikasi data dan mencegah kesalahan pembaruan
- Mengembangkan query SQL menggunakan VIEW, JOIN, dan SUBQUERY untuk menghitung total donasi setiap donatur serta persentase penggunaan dana secara otomatis
- Merancang ERD dengan menerapkan Generalization/Specialization untuk membedakan peran pengguna dan Composition untuk menggambarkan hubungan dalam pencatatan donasi

## Insight
- Mengurangi duplikasi data dan mencegah kesalahan pencatatan 
- Mempermudah analisis data keuangan untuk menampilkan informasi, seperti persentase penggunaan donasi secara otomatis
- Meningkatkan transparansi pengelolaan donasi sehingga pencatatan keuangan lebih mudah dipantau dan dipertanggungjawabkan
